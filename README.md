# Network Pong

Курсовой проект по дисциплине "Компьютерные сети и системы".

## Описание

Сетевая игра Ping Pong для двух игроков.

## Технологии

- C#
- .NET
- Windows Forms
- TCP Sockets

## Возможности

- Клиент-серверная архитектура
- Игра для двух игроков
- Передача данных по TCP
- Подсчет очков
- Определение победителя
